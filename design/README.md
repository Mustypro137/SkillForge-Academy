# Design mockup

Screens for SkillForge Academy (12 boards: light, dark and phone).
They are design files only. The app does not use them, and the tests do not check them.

- Live canvas (private, owner only): https://claude.ai/artifact/KWCoAMMFnxBwvUbdR5rk8d
- `mockup/*.dc.html` are the pages. `mockup/canvas.json` is the board layout.
- All numbers and names on the screens are sample data.
- These files need `support.js` from the Claude Design canvas, so they do not open alone in a browser. Use the live canvas.
